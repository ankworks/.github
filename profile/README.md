## Featured Project

### Aurelia Browser

**A modern Chromium-based browser designed for focus,
simplicity, and productivity.**

Aurelia is an experimental browser project built directly
on Chromium.

Current development focuses on Chromium integration,
a minimal New Tab experience, and a keyboard-first
Command Palette.

**Development status:** Experimental / Pre-alpha

## Development Philosophy

**Build with purpose.**

We believe good software should be useful,
maintainable, and thoughtfully designed.

Our development principles:

- **Simplicity** — Prefer clear solutions over unnecessary complexity.
- **Performance** — Build efficient and responsive software.
- **Transparency** — Develop open-source components in public.
- **Quality** — Prioritize testing, security, and maintainability.
- **Experimentation** — Explore new ideas through practical engineering.
